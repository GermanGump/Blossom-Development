    **ContentView.swift — Root ZStack architecture:**

    Replace the placeholder ContentView with the full ZStack layout:
    - Outer `ZStack(alignment: .bottom)` containing:
      1. A `TabView(selection: $selectedTab)` with each tab's content
      2. A `BlossomTabBar(selectedTab: $selectedTab)` overlaid at the bottom
    - `@State private var selectedTab: AppTab = .hubs` (default to Hubs for demo)
    - Each tab inside the TabView is wrapped in its own independent `NavigationStack`
    - Each tab applies `.tag(AppTab.xxx)` and `.toolbar(.hidden, for: .tabBar)` to hide native chrome
    - The TabView gets `.ignoresSafeArea(edges: .bottom)` so content extends under the custom bar

    The Hubs tab wraps `HubsView()` in a NavigationStack.
    All other tabs wrap `PlaceholderTabView(tab: .xxx)` in their own NavigationStack.

    Each non-Hubs tab also has a per-tab Route enum file for future use:

    ```swift
    // HomeNavigation.swift (and similar for Markets, Learn, Portfolio, Insights)
    import Foundation

    enum HomeRoute: Hashable {
        // Placeholder — routes added when features are built
    }
    ```

    **CRITICAL anti-pattern:** NavigationStack must be INSIDE each tab, never wrapping TabView. Each tab gets its own `NavigationStack` — not a shared one.

    **BlossomTabBar.swift — Custom scrollable tab bar:**

    Build as specified in 01-RESEARCH.md Pattern 5:
    - `VStack(spacing: 0)` with a `Divider()` separator on top (subtle gray line)
    - `ScrollView(.horizontal, showsIndicators: false)` containing `HStack(spacing: 0)`
    - `ForEach(AppTab.allCases)` rendering each tab as a tappable button
    - Each tab item: `VStack` with `Image(systemName: tab.icon)` and `Text(tab.rawValue)`
    - Selected tab: `BlossomTheme.tabActive` (teal) color for both icon and label
    - Unselected tabs: `BlossomTheme.tabInactive` (light gray) for both icon and label
    - Tab item width: `UIScreen.main.bounds.width / 5` to give comfortable spacing while allowing scroll
    - Background: `BlossomTheme.tabBarBackground` (systemBackground — white in light, dark navy in dark)
    - Frame height: ~60pt for the scroll area
    - Bottom safe area: Use `.safeAreaInset` or `GeometryReader` to add bottom safe-area padding (do NOT use the deprecated `UIApplication.shared.firstKeyWindow` pattern — use SwiftUI's GeometryReader or safeAreaInset instead, per research open question #3)
    - `@Binding var selectedTab: AppTab`

    **PlaceholderTabView.swift — Branded Coming soon screen:**

    Implement as specified in 01-RESEARCH.md code examples:
    - Centered vertically: large tab icon (56pt, teal), tab name as heading (title weight semibold, dark navy), "Coming soon" subtitle (subheadline, secondary)
    - Full-width, full-height background using `Color(UIColor.systemBackground)`
    - Use `BlossomTheme` colors — do NOT inline hex values

    Ensure all new files are added to the BlossomHubs target in Xcode.
