Create 2 new Swift files:

1. **PostCardView.swift** — `struct PostCardView: View` taking `community: Community`, `post: Post`, `isLocked: Bool`, `requiredTierName: String`, and `onUpgrade: () -> Void`. This is the router view that dispatches to the correct card subview based on post.postType:
   - `.text` -> TextPostCard(community:, post:)
   - `.tradeHighlight` -> TradeHighlightCard(community:, post:)
   - `.youtubeLink` -> YouTubeLinkCard(community:, post:)

   When `isLocked` is true, show the card metadata (PostAuthorRow, type indicator via post type icon, ticker tags if trade highlight) but wrap the body content in LockedContentOverlay(tierName: requiredTierName, onUpgrade: onUpgrade). Per user decision: blurred card preview showing full card layout (author, timestamp, type indicator, ticker tags) but blurring body content. Apply `.clipShape(RoundedRectangle(cornerRadius: 12))` on the card container to prevent LockedContentOverlay's .ignoresSafeArea() from bleeding outside card bounds (per RESEARCH.md Pitfall 1).

2. **ContentFeedViewModel.swift** — `@MainActor @Observable final class ContentFeedViewModel`. Takes `community: Community` in init. Properties:
   - `var selectedCollection: String? = nil` (nil = "All Posts")
   - `var collections: [String]` computed — unique sorted collection names from community.posts, excluding nil
   - `var filteredPosts: [Post]` computed — sorted by publishedAt descending, filtered by selectedCollection. Per user decision: when a collection is selected, show only posts matching that collection. Posts without a collection (nil) always show under "All" only (when selectedCollection is nil).
   - `func canAccess(post: Post, userTierIndex: Int?) -> Bool` — guard let userIndex else return false; return post.requiredTierIndex <= userIndex. Per CONTEXT.md: non-subscribers see ALL posts as locked.
   - `func tierName(for requiredIndex: Int) -> String` — returns community.tiers[requiredIndex].name or "Premium" as fallback.
   - Optional: `var filterToVideos: Bool = false` init parameter — when true, filteredPosts additionally filters to `.youtubeLink` type only (for .videos section reuse per RESEARCH.md Pattern 3).

Register both files in project.pbxproj.
