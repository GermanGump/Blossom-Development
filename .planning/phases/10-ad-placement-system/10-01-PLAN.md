Create all three ad view components. Each picks a creative once via `@State private var creative = AdCreative.xxxCreatives.randomElement()!` and wraps layout in `Link(destination: creative.destinationURL) { ... }.buttonStyle(.plain)`.

**BannerAdView.swift:**
- Full-width card using `blossomCard()` as base
- Layout: HStack with circular icon background (44x44, brand color at 15% opacity), headline (BlossomFont.subhead, semibold), subtitle (BlossomFont.caption, secondaryText), chevron.right trailing
- "Sponsored" / "Upgrade" label overlay at top-trailing corner (font size 10, secondaryText or violet for PRO)
- 1.5pt accent border using `RoundedRectangle(cornerRadius: 12).stroke(creative.accentColor.opacity(0.4))`
- Padding: 14pt internal, standard card styling
- Use `foregroundStyle()` not `foregroundColor()` per project convention

**InlineCardAdView.swift:**
- Feed-integrated card using `blossomCard()` as base
- Visual differentiator: 3pt left accent stripe using `UnevenRoundedRectangle(topLeadingRadius: 12, bottomLeadingRadius: 12)` filled with brand color
- Layout: HStack(spacing: 0) with left stripe + VStack content area (padded 14pt)
- Content: "Sponsored"/"Upgrade" label top-right, brand icon + brand name row, headline (subhead, semibold), subtitle (caption), CTA text "Learn More" / "Upgrade Now" in accent color
- No additional border overlay (the accent stripe IS the differentiator)

**PillAdView.swift:**
- Compact, lightweight — single HStack
- Layout: brand icon (20x20 circle), headline text (caption, 1 line), "Ad"/"Upgrade" trailing label in secondaryText
- Background: `BlossomTheme.cardSurface` with 8pt corner radius
- 1px border with cardBorder
- Padding: 10pt horizontal, 8pt vertical
- No `blossomCard()` — pill uses lighter styling than full cards

All three views must:
- Use `foregroundStyle()` not `foregroundColor()`
- Use BlossomFont tokens for all text
- Use BlossomTheme color tokens for semantic colors
- Support light and dark mode via theme tokens
- Have a #Preview block

**Do NOT add ScrollView or NavigationStack to any ad view** — they participate in host view layout contexts.
