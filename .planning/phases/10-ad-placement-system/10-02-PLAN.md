**HubsDiscoveryView.swift — Banner ad above Featured Hub:**

Insert `BannerAdView()` as a new item in the LazyVStack(spacing: 22), immediately BEFORE the `if let hero = heroCommunity` block (line 142). This is a flat insertion — no enumeration change needed. The banner sits right above "Featured Hub" regardless of whether My Hubs section is visible (per user decision: anchored to featured hub, consistent position).

**ContentFeedView.swift — Inline card ad between posts:**

1. Add `@State private var adInsertionIndex: Int = Int.random(in: 3...5)` as a new property on ContentFeedView.
2. Change the ForEach from `ForEach(viewModel.filteredPosts) { post in` to `ForEach(Array(viewModel.filteredPosts.enumerated()), id: \.element.id) { index, post in`.
3. Inside the ForEach body, BEFORE the PostCardView, add: `if index == adInsertionIndex { InlineCardAdView() }`
4. The adInsertionIndex @State is evaluated once at view init — deterministic per visit but varies between visits.
5. For short feeds (fewer posts than adInsertionIndex), the ad simply does not appear — the `if index == adInsertionIndex` never fires, which is the correct behavior.
6. CRITICAL: Do NOT add a ScrollView. ContentFeedView participates in the outer CommunityHubView scroll context (STATE.md decision Phase 06-02).

**CategoryExploreView.swift — Pill ads at cadence:**

1. Add `@State private var adCadence: Int = Int.random(in: 6...8)` as a new property.
2. Keep the existing two-ForEach structure (real communities + mock communities) — do NOT merge into a single array (preserves existing animation delay logic and divider).
3. Track a running card count across both ForEach loops using a helper. Approach: compute the total index for each card:
   - In the real communities ForEach: `let totalIndex = index` — insert `PillAdView()` after the card if `(totalIndex + 1).isMultiple(of: adCadence)`
   - In the mock communities ForEach: `let totalIndex = realCommunities.count + index` — insert `PillAdView()` after the card if `(totalIndex + 1).isMultiple(of: adCadence)`
4. The pill ad renders AFTER the community card at each cadence interval, not before.
5. Preserve existing `.opacity` and `.offset` animations on all community cards — only add pill ad views between them.
6. Preserve the "More Communities" divider between real and mock sections exactly as-is.
