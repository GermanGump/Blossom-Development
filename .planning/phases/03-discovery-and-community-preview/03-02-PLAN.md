**2. Create `CommunityPreviewView.swift`:**
- Init takes `communityID: String` — looks up community from `@Environment(CommunityStore.self)` by matching `community.id.uuidString == communityID`
- Creates `@State private var viewModel: CommunityPreviewViewModel` initialized with the found community
- `@State private var showTiers = false` for sheet presentation

**Layout (ScrollView body):**

a) **Parallax banner** at top:
- `Color.clear.frame(height: 240)` container
- Inside `.overlay`:
  - If `community.bannerImageName` exists: `Image(bannerImageName).resizable().scaledToFill()`
  - Else: `LinearGradient(colors: [BlossomTheme.violet, BlossomTheme.teal], startPoint: .topLeading, endPoint: .bottomTrailing)` as fallback
- Apply `.visualEffect { content, proxy in }` on the image/gradient:
  - Read `proxy.frame(in: .scrollView).minY`
  - When `offsetY > 0`: apply `.offset(y: -offsetY * 0.4)` for parallax
  - Always `.clipped()` on the container
- `.clipped()` on the outer `Color.clear.frame(height: 240)` container

b) **Creator avatar overlapping banner**:
- Use negative offset or `overlay(alignment: .bottom)` on banner container
- `AvatarView(imageName: community.creator.profileImageName, preset: .xlarge, showVerifiedBadge: community.creator.isVerified)`
- Offset so avatar center sits on the bottom edge of the banner
- White circle stroke behind avatar for visual separation from banner

c) **Content section** below avatar (VStack, left-aligned, padded):
- Value proposition tagline: `community.name` in `BlossomFont.title` + category `TagView` below
- Creator bio section:
  - HStack: smaller `AvatarView(imageName:preset:.medium)` + VStack(creator.name in headline + VerifiedBadge inline, creator.username in caption secondaryText)
  - `community.creator.bio` in `BlossomFont.body`
- Full description: `community.description` in `BlossomFont.body`, `BlossomTheme.primaryText`

d) **Social proof section** (VStack with `.blossomCard()` or subtle background):
- Member count: `Image(systemName: "person.2.fill")` + "\(community.memberCount) members" in `BlossomFont.subhead`
- Row of member avatars: 4-5 small overlapping circles (use system person.circle.fill with varying colors, or reuse ambassador photos from other communities if available). This is a visual element — the specific avatars are Claude's discretion.
- Testimonial-style quote: A hardcoded testimonial quote per community (Claude's discretion on content). Italic text, attributed to a member name. Wrap in a card with subtle left border accent in `BlossomTheme.violet`.

e) **Spacing and padding**: 16pt horizontal padding on content, 24pt between major sections.

**Sticky CTA bar at bottom:**
- `.safeAreaInset(edge: .bottom)` (NOT ZStack overlay)
- VStack: `Divider()` + `BlossomPrimaryButton` with text "View Tiers"
- Button action sets `showTiers = true`
- Background: `BlossomTheme.background`
- Padding: 16pt horizontal, 12pt vertical

**Sheet presentation:**
- `.sheet(isPresented: $showTiers)` presents `TiersBottomSheet(tiers: community.tiers, popularTierIndex: viewModel.popularTierIndex)`
- `.presentationDetents([.fraction(0.55), .large])`
- `.presentationDragIndicator(.visible)`

**Custom back button:**
- `.navigationBarBackButtonHidden(true)`
- `.toolbar { ToolbarItem(placement: .topBarLeading) { ... } }` with custom HStack:
  - `Image(systemName: "chevron.left")` font .system(size: 16, weight: .semibold)
  - `Text("Communities")` in `BlossomFont.subhead`
  - Both in `BlossomTheme.violet`
  - Button action: `@Environment(\.dismiss) private var dismiss` and call `dismiss()`
