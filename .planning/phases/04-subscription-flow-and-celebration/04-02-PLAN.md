  <action>
    Create BlossomHubs/Features/Hubs/Payment/ConfettiCelebrationView.swift as a standalone reusable view (per STATE.md recommendation: build standalone prototype early before integrating).

    The view accepts: communityName (String), onContinue (() -> Void) callback.

    Structure:
    - ZStack with dark semi-transparent background (Color.black.opacity(0.6))
    - Center: Blossom logo image ("blossom-logo-light" from asset catalog), scaled ~80pt
    - Below logo: "Welcome to [communityName]!" text in BlossomFont.title, white color
    - Below text: "Enter Community" button using BlossomPrimaryButton style, calls onContinue
    - Overlaid: ConfettiCanvasView (the particle layer) using .allowsHitTesting(false)

    ConfettiCanvasView (private struct within same file):
    - Uses Canvas + TimelineView(.animation) pattern from 04-RESEARCH.md Pattern 3.
    - ConfettiParticle struct: id (UUID), x/y (CGFloat), velocityX/velocityY (CGFloat), rotation/rotationSpeed (Double), opacity (Double), color (Color), shape enum (circle, rectangle, strip).
    - Spawn ~100 particles on .onAppear with burst-from-center physics: random angle 0...2pi, random speed 200...600, velocityY biased upward (subtract 300), random rotation and rotation speed.
    - Canvas renders each particle at position: centerX + particle.x + velocityX * t, centerY + particle.y + velocityY * t + 0.5 * gravity * t^2 (gravity = 800).
    - Opacity fades: max(0, 1.0 - elapsed * 0.4) so particles fade over ~2.5 seconds.
    - Draw different shapes based on particle.shape: circle (Path(ellipseIn:)), rectangle (Path(CGRect)), strip (narrow tall rect).
    - Colors: [BlossomTheme.violet, BlossomTheme.orange, BlossomTheme.teal] randomly assigned per particle.
    - @State startTime: Date? set on .onAppear alongside particle spawn.

    Animation flow:
    - Button appears with a slight delay (.opacity transition, appears after 0.8 seconds using DispatchQueue.main.asyncAfter or .task { try? await Task.sleep }).
    - @State showButton = false, set to true after delay.

    Haptic feedback: Fire UINotificationFeedbackGenerator().notificationOccurred(.success) on .onAppear when confetti spawns. Also add .sensoryFeedback(.impact, trigger: showButton) for the button appearance.

    Register file in project.pbxproj under Features/Hubs/Payment/ group.
