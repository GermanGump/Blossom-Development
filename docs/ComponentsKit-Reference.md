# ComponentsKit Reference

**Source:** https://github.com/componentskit/ComponentsKit
**Install:** Swift Package Manager — `https://github.com/componentskit/ComponentsKit.git`
**Platforms:** UIKit + SwiftUI (both supported)

## Available Components (18)

1. **Alert** — Dialog/alert notification
2. **Avatar** — User profile image display
3. **AvatarGroup** — Multiple avatars grouped
4. **Badge** — Label or notification badge
5. **Button** — Interactive button
6. **Card** — Container for grouped content
7. **Checkbox** — Selection checkbox
8. **CircularProgress** — Circular progress indicator
9. **Countdown** — Timer/countdown display
10. **Divider** — Visual separator
11. **InputField** — Text input control
12. **Loading** — Loading state indicator
13. **Modal** — Modal dialogs (Bottom Modal + Center Modal variants)
14. **ProgressBar** — Linear progress indicator
15. **RadioGroup** — Radio button selection
16. **SegmentedControl** — Segmented control picker
17. **Slider** — Value slider
18. **TextInput** — Text input field

## Most Relevant for Blossom Communities

| Component | Use Case in Communities |
|-----------|----------------------|
| **Avatar / AvatarGroup** | Creator profile pics, community member avatars, subscriber lists |
| **Badge** | Verified creator badge, tier badges, notification counts, "NEW" content markers |
| **Button** | Subscribe CTAs, tier selection, forum post/reply actions |
| **Card** | Community preview cards, content feed posts, tier cards, FAQ entries |
| **Modal** | Payment flow (bottom sheet), tier details expansion, subscription confirmation |
| **InputField / TextInput** | Discussion forum post creation, FAQ question submission, community setup forms |
| **SegmentedControl** | Content tab switching (Posts / Discussions / FAQ / Videos) |
| **CircularProgress** | Loading states during payment simulation |
| **Loading** | Content feed loading states |
| **Divider** | Section separators in community landing pages |
| **Alert** | Subscription confirmation, cancel subscription warning |
| **Checkbox** | Permission settings in creator dashboard |
| **RadioGroup** | Tier selection during subscription flow |
| **ProgressBar** | Earnings goal tracking in creator dashboard |

## Integration Notes

- Add via SPM in Xcode: File → Add Packages → paste repo URL
- Import: `import ComponentsKit`
- All components have SwiftUI-native implementations
- Components can be themed/styled to match Blossom brand colors
